# 🚀 ABTalks 60 Days Data Science Challenge

Welcome to my **60 Days Data Science Challenge by ABTalks**.

This repository documents my journey of learning and practicing **Python, Data Science, Machine Learning, and related technologies** through daily hands-on tasks.

## 📌 Challenge Goal

The goal of this challenge is to build strong fundamentals and develop practical Data Science skills by completing a task every day for 60 days.

---

## 📅 Day 1 — Python Fundamentals Bootcamp

### 🎯 Objective

Build a strong foundation in Python by practicing:

* Variables
* Data Types
* Input and Output
* Basic Operators
* Lists
* Dictionaries
* Basic calculations

### 📝 Task

The Day 1 program:

1. Takes the user's **name**
2. Takes the user's **age**
3. Takes the user's **monthly salary**
4. Calculates the **yearly salary**
5. Stores the information in a Python dictionary
6. Displays the collected information

### 🛠️ Technologies Used

* Python 3

### 📂 Project Structure

```text
60-days-data-science/
│
├── day1.py
└── README.md
```

### ▶️ How to Run

Make sure Python is installed on your system.

Run the following command:

```bash
python day1.py
```
